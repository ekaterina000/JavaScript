Сначала устнавовить виртуальную среду через -npm install
Запускать через -npm run dev

1 тест 
тест на восприятие времени
нажимаем кнопку с количеством секунд, и по ощущению, когда пройдет указанное на кнопке количество секунд, нажимаем еще раз кнопку, получаем результат отклонения от указнного времени.

2 тест 
тест струпа
нам надо указывать цвет которым написано слово, а не значение слова.

3 тест 
тест на память
дается 5 секунд после запуска чтоб запомнить карточки, потом начинается отсчет времни, а мы на скорость должны найти пары карточек. переворачивать за раз можно по две карточки.

4 тест
тест на реакцию
у нас есть сетка с квадратами и как можно быстрее надо нажать на загоревшийся зеленым цветом квадратик


5 тест
тест струпа 2
здесь появляются круги а нам надо выбрать только те, которые больше. не надо обращать внимание на цифры в кружочках.

6 тест 
Тест на психомоторную бдительность

в данном тесте нам надо собирать только круги как можно быстрее.
